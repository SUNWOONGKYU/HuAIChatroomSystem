## 검증 상태

- 통과: in-memory 상태 머신이 `pending → plan_pending → approved → executing → security_requested → security_responded → approved → generated → revision_requested → revision → approved → completed`로 전이
- 통과: 방장 승인은 `5001`, 보안 응답은 `security-fixture`, 실행·수정은 `code-worker-fixture`로 actor 검증
- 통과: 3회 revision 각각 전체 SHA-256 및 변경 전·후 SHA-256 기록
- 통과: 게임 시작·키보드 이동·보물 획득·재시작 브라우저 실행
- 통과: 보안 요청은 fixture 전용이며 실제 권한·시크릿·운영 데이터에 접근하지 않음
- 미실행: 별도 브라우저 도구 화면 세션 확인 — 테스트 내부 Chromium 검증은 완료했으나 외부 브라우저 도구 세션은 사용하지 않음
