# _archive/gates/ — 과거 Gate/Phase 작업기록 보관

이 폴더는 개발 과정에서 생성된 GATE/PHASE 완료 기록, 작업 단계 요구사항 문서, 과거 검증
리포트, 작업기록(mbo-천상 phase 완료 노트 등)을 저장소 루트에서 옮겨 보관하는 곳입니다.

**이 폴더는 현재 시스템 상태의 증거가 아닙니다.** 여기 있는 문서는 작성 당시 시점의
스냅샷이며, 이후 코드·문서가 계속 바뀌었을 수 있습니다. 현재 상태를 확인하려면 루트의
`README.md`, `OPERATION_STATUS.md`, `SYSTEM_DOCUMENTATION_SYNC.md`, `docs/` 를 봅니다.

일부 파일(`2026_08_10__GATE19_OPERATION_RUNBOOK.md` 등)은 여전히 `npm run verify:structure`,
`npm run verify:operation-runbook` 테스트가 내용을 확인하는 대상이므로, 이름이나 내용을
바꾸기 전에 `scripts/verify-structure.mjs`, `scripts/verify-operation-runbook.test.mjs` 를
같이 확인하세요.
