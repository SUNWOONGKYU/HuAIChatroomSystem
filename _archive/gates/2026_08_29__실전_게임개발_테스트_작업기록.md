# 실전 게임 개발 합성 테스트 작업기록

## 목표

가상 방장·참여자 대화에서 시작해 새 게임 개발, 3회 수정, 승인·보안 요청·응답, 최종 브라우저 검증까지 운영 흐름을 격리 환경에서 재현한다.

## 단계

- [x] 가상 대화 및 역할 분리
- [x] 작업 계획·승인 흐름
- [x] 새 게임 초안 생성
- [x] 수정 1 및 승인
- [x] 수정 2 및 승인
- [x] 수정 3 및 승인
- [x] 보안 요청·가상 응답
- [x] 최종 브라우저 검증·결과표

## 안전 범위

실제 인간 계정, 운영 Telegram 메시지, 운영 DB, 실제 시크릿·권한 상승을 사용하지 않는다. 모든 외부 액션은 테스트 fixture 또는 synthetic webhook으로 대체한다.

## 결과

새 보물 수집 러너 합성 흐름은 20단계 상태 전이, 3회 revision, 브라우저 핵심 여정을 통과했다. 기존 게임 3건의 로컬 fixture·순차 실행 문제, 잘못된 actor 거부 검증, revision별 전체 SHA-256 before/after 증거를 보완했고, 네 게임 브라우저 테스트와 typecheck/build/diff-check를 모두 통과했다.
